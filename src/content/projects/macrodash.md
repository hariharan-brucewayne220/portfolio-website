Real-Time Financial Intelligence Platform

Built a comprehensive financial analytics dashboard that combines market data from multiple sources with AI-powered analysis tools for informed decision-making.

## Key Achievements

- Built a real-time financial analytics platform using React 19, TypeScript, Django REST Framework, and PostgreSQL, integrating 7+ external APIs (FRED, Yahoo Finance, Alpha Vantage, CoinMarketCap) to deliver stock market data, economic indicators, and cryptocurrency tracking

- Implemented professional-grade technical analysis indicators (RSI, MACD, Bollinger Bands, SMA/EMA) using TA-Lib with interactive Recharts visualizations and multi-timeframe support (1D to 5Y)

- Developed AI-powered features with OpenAI GPT-4 and Google Gemini integration for stock analysis, news sentiment scoring, and natural language financial insights

- Engineered automated price alert system with APScheduler background jobs, JWT authentication, user-specific watchlists, and email notifications for 600+ concurrent alerts
